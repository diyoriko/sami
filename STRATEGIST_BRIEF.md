## Что такое Sami

Telegram-сообщество для людей, которые хотят двигаться каждый день. Только коврик. С инвентарём или без. Стретчинг, мобильность, сила — видео-тренировки, которые можно делать дома или где угодно.

Миссия: тёплая, честная и эстетичная среда для заботы о теле.
One-liner: "Не мотивация. Структура."

**Амбиция:** продукт всероссийского масштаба. Telegram-сообщество — первый этап. Далее — приложение, маркетплейс тренеров, AI-фидбек, B2B. Цель — стать платформой №1 для ежедневных домашних тренировок в России.

## Как устроено сообщество

### Канал "Сами" (@sami_workouts)

Канал = лента тренировок. Бот ежедневно постит видео-тренировки.

**Формат поста:**
- Видео-файл (загружен в Telegram, не ссылка на YouTube — YouTube заблокирован в России)
- Название тренировки: без капса, болдом, переведено на русский
- Моно-теги в бэктиках: вид тренировки, длительность, группы мышц, уровень сложности, инвентарь
- Рейтинг: ⭐ оценка по алгоритму (0.35*views + 0.30*likes + 0.20*channel + 0.15*completions)
- Автор: имя канала-источника + ссылка на оригинал
- Хештеги (планируется): #категория #мышцы #уровень #сезонN — нативная фильтрация в Telegram

**Без inline-кнопок в канальных постах** — Telegram показывает нативную "Комментировать".
Бот пишет автокоммент в discussion group с кнопкой "Я сделаль". Планируется: при нажатии кнопки бот пишет комментарий с именем, стриком и общим счётчиком (вместо редактирования inline-кнопки).

**Расписание:**
- Автопоиск видео: 19:00 МСК (approval flow → админ выбирает → публикует вручную)
- Автопостинг по расписанию ОТКЛЮЧЁН — публикация только вручную через /post или кнопку "Опубликовать"

### Группа (обсуждения канала)

Группа привязана к каналу как комментарии. Название: "Сами Daily". Участники обсуждают тренировки, делятся впечатлениями.

### Бот @sami_workout_bot ("Сами botik")

Бот — интерфейс взаимодействия с сообществом.

**Закреплённые кнопки внизу (persistent menu):**
- "Предложить тренировку" — UGC-флоу (YouTube-ссылка → категория → сложность → название → модерация)
- "Мои тренировки" — список загруженных пользователем тренировок со статусами
- Admin-кнопки: Поиск, Статус, Опубликовать, Аналитика, Сбросить

**Модерация:**
- Math captcha при вступлении → мут до решения → quiz по целям → unmute
- Auto-delete внешних ссылок и спама → предупреждение → мут → бан
- /report — пожаловаться на сообщение

**Виды тренировок (7 категорий, SSoT в shared.ts):**
- 🧘 Стретчинг
- 💪 Сила
- 🐍 Мобильность
- 🧘‍♂️ Йога
- 🫁 Дыхание
- 🧊 Восстановление
- 🏃 Кардио

У каждой категории: эмодзи, RU-название, YouTube-ключевые слова для поиска (8 запросов на категорию).

### EPIC: Сезоны + Ежедневный челлендж (утверждён, в бэклоге)

Трансформация канала из каталога видео в структурированный ежедневный челлендж:
- **7 дней = 7 категорий:** Пн стретчинг, Вт сила, Ср мобильность, Чт йога, Пт кардио, Сб дыхание, Вс восстановление
- **21-дневные сезоны** — 3 полных недели = 1 сезон, потом новый
- **Хештеги** — `#стретчинг #спина #начинающий #сезон1` в каждом посте, кликабельные для нативной фильтрации в Telegram

- **Публикация с подсказкой** — бот показывает админу текущий сезон, день и категорию дня

Это решает: контент-расписание, фильтрацию, retention (серии), вовлечение (социальное давление комментариев).

## Рыночный контекст (Россия)

### Рынок фитнеса в РФ
- **Офлайн-фитнес:** 262,8 млрд ₽ (2024), рост +23%. Проникновение фитнес-клубов — ~4,7% населения (~7,1 млн человек). Источник: fitness-pro.ru
- **Онлайн-фитнес:** 4,8 млрд ₽ выручки топ-25 платформ (2024), рост +37%. Прогноз: до 42 млрд ₽ к 2032 (CAGR ~20-30%). Источники: sostav.ru, smartranking.ru
- **Подписки онлайн в 3 раза дешевле залов:** ~10 тыс. ₽/год vs ~30 тыс. ₽/год
- **YouTube ограничен в РФ** — специализированные удобные решения отсутствуют

### Конкуренты
- **FitStars** — лидер онлайн-фитнеса РФ, ~1,2 млрд ₽ выручки (2024, +87% г/г). Модель: интеграции с блогерами, массовые челленджи
- **InsideOut, Anyclass, Spirit.Fitness** — средние игроки (сотни млн ₽), курсы и программы
- **Международные:** Apple Fitness+, Peloton, Strava (135+ млн пользователей), Headspace/Calm

### Почему SAMI отличается
- Ритуалы + AI + социальная сеть + маркетплейс тренеров
- Bodyweight-first, zen-минимализм, без токсичной мотивации
- Адаптация под российские реалии (YouTube заблокирован, СБП вместо карт, RuStore/AppGallery вместо Play Store)

## Монетизация — ПРИОРИТЕТНОЕ ИССЛЕДОВАНИЕ

**Контекст:** Владелец проекта хочет создать продукт всероссийского масштаба с амбицией на выход (acquisition). Telegram-сообщество — MVP и точка роста аудитории. Далее — приложение, платные функции, B2B.

**Задача стратегу:** Провести глубокий ресерч моделей монетизации для SAMI с учётом:

### 1. Модели подписки
- Ценовой диапазон для РФ: 449-699 ₽/мес, 3 990-5 490 ₽/год
- Что входит в бесплатный доступ vs premium?
- Как не убить UX сообщества платным барьером?
- Опыт FitStars (1,2 млрд ₽) и международных игроков

### 2. Маркетплейс тренеров
- Комиссия 15-25% с платных тренировок
- Когда запускать? При каком размере аудитории?
- Как привлечь первых тренеров?
- Платные и бесплатные тренировки на одной площадке

### 3. AI Premium
- Персонализированные планы, обратная связь по технике
- Анализ прогресса пользователя
- Стоимость и готовность аудитории платить

### 4. B2B-направление
- Корпоративные пакеты для команд
- Wellbeing-программы для компаний
- Ценообразование и каналы продаж

### 5. Переход Telegram → Приложение
- Когда начинать разработку приложения?
- Как сохранить Telegram-аудиторию при миграции?
- Дистрибуция: RuStore, AppGallery, VK Mini Apps (Google Play в РФ не работает)
- Платежи: СБП (13,4 млрд операций в 2024), веб-чекаут

### 6. Unit-экономика
- Целевые метрики: DAR (Daily Active Rituals), D30 Retention, LTV/CAC >3
- При каком размере аудитории монетизация становится viable?
- Путь к ARR 100-300 млн ₽

**Важно:** Монетизация не должна противоречить ценностям бренда. "Не мотивация. Структура." Никаких токсичных паттернов, dark patterns, фальшивого дефицита. Модель должна ощущаться как справедливый обмен ценности.

## Автопостинг — ИССЛЕДОВАНИЕ

**Контекст:** Сейчас автопостинг отключён. Бот ищет видео в 19:00 МСК (approval flow), админ вручную выбирает и публикует через кнопку "Опубликовать". Расписание задумано: 07:30 стретчинг, 12:00 силовая, 19:00 мобильность.

**Задача стратегу:** Проанализировать и рекомендовать оптимальный режим публикации:

1. **Ручной vs автоматический** — что лучше на текущем этапе (мало подписчиков)?
2. **Оптимальное время публикации** — когда аудитория активнее? Одинаковое ли время для всех категорий?
3. **Частота** — 3 поста в день (текущий план) или другой ритм? Есть ли риск "утопить" контент при малой аудитории?
4. **Качество vs количество** — лучше 1 отличное видео в день или 3 средних?
5. **Гибридный режим** — автопост для стретчинга утром, ручной для остальных?

Рекомендация должна учитывать текущий размер сообщества и планы роста.

### Ценности

| Ценность | Как проявляется |

| Жить лучше, а не быстрее похудеть | Без контента про похудение, жиросжигание, "до/после" |
| Тело = партнёр, не проект | Без "исправь недостаток", без "идеального тела" |
| Красиво во всём | Светлая палитра, честные фото, минимализм |
| Поддержка, не соревнование | Без рейтингов между людьми, без таблиц лидеров |
| Нужен только коврик | Только bodyweight (инвентарь опционален) |
| Реальные люди и результаты | Пот, усилие — без ретуши |

### Tone of Voice

Спокойно, конкретно. Тренер-методист, не инфлюенсер.
- "6 минут, чтобы плечи сказали спасибо"
- "Пульс поднимется на ~20 уд/мин — нормально, держи темп"
- Без: "ПОГНАЛИ", "жиросжигание", "до/после", капс

### Позиционирование
- ICP: 28-40, живут в ритме города, хотят регулярности без зала
- Отстройка: bodyweight-first, zen-минимализм, без токсичной мотивации
- One-liner: "Не мотивация. Структура."
- North Star: DAR (Daily Active Rituals) — доля пользователей, выполняющих ежедневный ритуал
