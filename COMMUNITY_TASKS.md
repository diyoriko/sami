### P0: Архитектура Telegram-присутствия — стратег решает (Фаза 1: стабильная версия)

Ключевой вопрос: **канал или группа как основная площадка?**

Проблема: канал — односторонний. Пользователи не могут фильтровать видео, искать, взаимодействовать с контентом. Фильтры, профиль, UGC — только через DM с ботом, что неудобно.

Варианты для анализа:
1. **Группа как основная** — посты в группу, бот отвечает на команды в контексте. Минусы: шум, нет "ленты"
2. **Канал + группа (текущее)** — канал для контента, группа для общения. Минусы: интерактивность ограничена
3. **Канал + inline-бот** — `@sami_workout_bot фильтр` в любом чате. Без DM
4. **Канал + mini app** — Telegram Mini App для каталога. Полный UI. Минусы: сложнее
5. **Гибрид** — канал для постов, группа для интерактива с ботом

Стратег анализирует: конкуренты (10K+ каналы), вовлечение на старте (3-50 чел.), масштабируемость. Решение влияет на ВСЮ архитектуру — принять до начала реализации.
